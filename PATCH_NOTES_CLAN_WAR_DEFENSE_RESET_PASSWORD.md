# Патч: защита арен, анти-монополия и защищённый сброс кланового сезона

## Защита арен
- Если на арену клана идёт активная атака, победы участников клана-владельца теперь автоматически работают как защита.
- Защитная победа уменьшает чистый прогресс атаки на значение `clan_war_defense_win_power`.
- В карточке арены отображается прогресс атаки, количество побед атаки и очки защиты.
- Защитные победы также попадают в личный вклад игрока в клановых войнах.

## Анти-монополия
Добавлены настройки через `game_settings`:
- `clan_war_max_owned_arenas` — максимум арен, которые может держать один клан.
- `clan_war_leader_capture_extra_wins` — дополнительные победы для захвата за каждую уже удерживаемую арену.
- `clan_war_capture_shield_hours` — щит после захвата, чтобы арену нельзя было сразу перезахватить.
- `clan_war_same_arena_cooldown_hours` — КД для старого владельца на повторную атаку этой же арены.

## Сброс кланового сезона
- Перед сбросом админ видит текущие награды топ-5 кланов.
- Сброс заблокирован, если награды топ-5 вообще не проставлены.
- Для сброса требуется отдельный пароль главного админа: `Ihbsn_3141592`.
- Пароль также хранится в настройке `clan_season_reset_password`, его можно менять через настройки.
- В историю кланового сезона пишется Telegram ID администратора, выполнившего сброс.
