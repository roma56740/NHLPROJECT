# Патч: дивизионы, анимация паков, зарплаты и награды

## 1. Дивизионы команд

Добавлен новый админ-раздел: **🏒 Дивизионы**.

Что можно делать:

- создавать дивизион вручную;
- открывать дивизион и видеть все команды, которые уже есть в карточках бота;
- добавлять/убирать команды из дивизиона через кнопки;
- если команда была в другом дивизионе, при выборе она переносится в новый;
- загружать картинку дивизиона;
- включать/выключать дивизион.

Новые таблицы:

- `team_divisions`
- `team_division_teams`

## 2. Анимация открытия паков

Анимация открытия пака теперь строится по логике:

1. дивизион;
2. команда;
3. национальность игрока;
4. итоговая карточка.

Раньше на первом этапе вместо дивизиона фактически использовалась коллекция. Теперь дивизион берётся из привязки команды к дивизиону.

Для этапов анимации можно загружать картинки:

- картинка дивизиона;
- картинка команды;
- картинка страны/национальности;
- финальная картинка карточки игрока.

Если картинка загружена, бот отправляет её вместе с текстом в одном сообщении через `photo + caption`.

Новая таблица:

- `animation_assets`

Новые настройки:

- `pack_animation_enabled`
- `pack_animation_step_delay_ms`

## 3. Проверка недостающих картинок и данных

Добавлена автоматическая проверка недостающих данных.

Бот проверяет:

- карточки без фото;
- карточки без команды;
- карточки без страны;
- активные паки без картинки;
- дивизионы без картинки;
- команды без дивизиона;
- команды без картинки для анимации;
- страны без картинки для анимации.

Если есть проблемы, бот отправляет предупреждение всем активным администраторам.

По умолчанию предупреждение повторяется каждые **2 часа**.

Новые настройки:

- `asset_warning_enabled`
- `asset_warning_interval_hours`
- `asset_warning_last_sent_at`

## 4. Управление зарплатами

Добавлен новый админ-раздел: **💵 Зарплаты**.

Возможности:

- посмотреть сводку по зарплатам;
- показать всех игроков с зарплатой `0`;
- показать самых дорогих игроков;
- поставить зарплату сразу всей коллекции;
- поставить зарплату только тем картам коллекции, у которых сейчас `0`;
- заполнить все нулевые зарплаты одним значением;
- массово поставить зарплату по диапазону OVR, например `90-93 5.5`.

## 5. Центральное меню наград

Добавлено меню **🎁 Награды**.

Оно собирает в одном месте переходы к редактированию наград:

- награды за матчи;
- ежедневный вход;
- награды сезона;
- бонусы креаторов;
- квесты;
- события;
- Hockey Pass.

Также добавлена техническая таблица `reward_settings` для дальнейшего расширения единой системы редактируемых наград.
