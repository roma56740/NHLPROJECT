# Патч: OVR > 99, кланы, бесплатные коллекции, уровни админки

## OVR состава выше 99
- Убрано ограничение итогового OVR состава на 99.
- Итоговый OVR состава теперь считается как средний OVR карточек + бонус химии без верхнего среза.
- Бот-соперник в матчах тоже больше не ограничивается 99 OVR, чтобы корректно подстраиваться под усиленные составы.

## Кланы: статистика игрока
- В управлении составом клана добавлена кнопка «📊 Статистика игрока».
- Президент и вице-президент могут открыть статистику участника клана: лига, рейтинг, матчи, победы, поражения, голы, OVR состава и лучшие карты.

## Несколько коллекций для бесплатных карточек
- Бесплатная карточка теперь может выпадать не из одной, а из нескольких коллекций.
- В админке бесплатных карточек добавлены действия:
  - добавить коллекцию в общий пул;
  - убрать коллекцию из пула;
  - заменить весь список одной коллекцией.
- При получении бесплатной карточки бот выбирает случайную активную карту из общего пула всех выбранных коллекций.
- Старая настройка одной коллекции сохранена для совместимости, но основной список теперь хранится в `free_card_collection_codes`.

## Уровни админки
- Добавлена ролевая админка через таблицу `bot_admins.role`.
- Главные админы из `.env` получают роль `owner` и полный доступ.
- Админов теперь можно добавлять с выбором уровня доступа.
- Уровень доступа можно менять через админ-панель.
- Главного админа из `.env` нельзя снять или понизить через панель.

## Роли
- `owner` — полный доступ, выдача админок, выгрузка базы и архивов.
- `senior_admin` — почти полный доступ без выдачи админок и выгрузки базы.
- `content_admin` — карты, массовая загрузка, паки, стартовый набор, дивизионы, картинки, зарплаты, химия, награды.
- `economy_admin` — награды, магазин, паки, промокоды, квесты, события, Hockey Pass, ежедневный вход, креаторы.
- `moderator` — пользователи, безопасность, кланы, обмены, рассылка, рейтинг.
- `clan_admin` — кланы, арены, обмены и рейтинг.
- `analyst` — сводка и рейтинг без опасных действий.

## Защита от лишних действий
- Добавлен middleware прав админки.
- Если админ без нужного уровня нажмёт закрытый раздел, бот покажет отказ и не выполнит действие.
- Обычные игроки не блокируются из-за совпадающих кнопок вроде «🎁 Паки» или «🎁 Бесплатная карточка».
