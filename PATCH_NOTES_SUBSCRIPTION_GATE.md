# Патч: обязательная подписка и стартовая картинка

## Добавлено

- Обязательная подписка на Telegram-канал перед использованием бота.
- Канал подписки настраивается через админ-панель: `⚙️ Настройки`.
- Добавлены настройки:
  - `subscription_required_enabled` — включить/выключить обязательную подписку;
  - `subscription_channel_id` — @username канала или числовой ID `-100...`;
  - `subscription_channel_url` — ссылка для кнопки подписки;
  - `start_banner_path` — путь к картинке стартового сообщения.
- Если игрок не подписан, любые сообщения и кнопки блокируются, а бот отправляет сообщение с кнопками:
  - `Подписаться на канал`;
  - `Проверить подписку`.
- После успешной проверки подписки бот автоматически открывает стартовое меню.
- Администраторы не блокируются проверкой подписки.
- Стартовое сообщение `/start` теперь отправляется с картинкой `assets/visual/start_banner.jpeg`.

## Важно для настройки

- Для проверки подписки бот должен быть добавлен в канал администратором.
- В `subscription_channel_id` лучше указывать `@channel` для публичного канала или `-100...` для приватного канала.
- Если канал приватный, в `subscription_channel_url` нужно указать invite-ссылку для кнопки.
- Если `subscription_required_enabled = 0`, проверка полностью выключена.
