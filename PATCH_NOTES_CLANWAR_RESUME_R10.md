# R10 — Clan War 2.0 stuck-match / resume fix

## Симптом

После запуска Clan War 2.0 пользователь мог потерять сообщение с War Roulette/Draft,
а повторное нажатие «Найти матч» показывало только «У вас уже идёт матч».
В результате в UI не было способа вернуться к уже созданному `war2_matches`.

Скриншот воспроизводит именно этот сценарий: глобальный `player_match_locks` уже
привязан к Clan War 2.0, но пользователь находится вне экрана драфта.

## Что изменено

- В главном экране Clan War 2.0 незавершённый матч теперь определяется автоматически.
- Вместо новой попытки матчмейкинга появляются:
  - `▶️ Продолжить матч`
  - `❌ Отменить текущий матч`
- Повторное нажатие `🎲 Найти матч`, если War 2.0 уже идёт, восстанавливает текущий
  экран вместо alert «матч уже идёт».
- Resume восстанавливает правильную стадию:
  - Clone War до сборки состава;
  - Clone War после сборки — экран подтверждения;
  - незавершённый Draft — текущий раунд;
  - законченный Draft — экран подтверждения / Wild Card.
- Для старых матчей без draft pool пул создаётся идемпотентно при resume.
- Каждый реальный пользовательский шаг в War 2.0 обновляет heartbeat lock'а.
- 10-минутный inactivity timeout теперь считается по heartbeat, а не только по
  `war2_matches.created_at`.
- Очистка заброшенных War 2.0 выполняется автоматически каждые 120 секунд и при
  запуске бота; старый `drafting` больше не может бесконечно продлевать общий lock.
- Если drafting-матч жив, но его lock потерялся после сбоя/рестарта, resume безопасно
  восстанавливает lock и привязывает его обратно к `match_id`.
- Старое Telegram-сообщение с кнопкой «Отменить» больше не может снять lock с нового
  матча: lock снимается только если отменён именно текущий `match_id`.
- Ошибка внутри `start_war2_match()` после создания записи теперь переводит созданный
  матч в `abandoned`, а не оставляет ghost `drafting`.

## Проверки

- `python -m compileall app` — OK.
- `python -m compileall tests` — OK.
- Сервисный SQLite regression scenario — OK:
  - heartbeat сохраняет живой draft;
  - stale heartbeat закрывает draft и освобождает lock;
  - потерянный lock восстанавливается;
  - stale cancel не снимает lock нового матча;
  - старый ghost draft не снимает lock более нового матча.
- Добавлены regression tests в `tests/test_war2.py` для R10.

Полный pytest в текущем контейнере не запускался: пакет `aiogram` здесь не установлен.
