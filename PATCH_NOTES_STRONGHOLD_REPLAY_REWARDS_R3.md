# Stronghold reward/rating isolation — R3

Исправлено:

- Stronghold больше не изменяет обычный рейтинг игрока.
- Stronghold больше не меняет обычную лигу.
- Stronghold больше не выдаёт стандартную награду за победу (например, 750 Coins).
- Stronghold не выдаёт Rank Points обычного режима.
- Матчи Stronghold больше не двигают обычные match quests/event progress.
- Повтор уже пройденного Fortress-этапа даёт:
  - 0 FT
  - 0 Coins
  - 0 Event XP
  - 0 прогресса Stronghold-миссий
- Первый проход этапа продолжает работать по прежним правилам.
- Повторный проигрыш уже пройденного этапа больше не сбрасывает статус WON и не блокирует следующие этапы.
- Звёзды при повторе не уменьшаются.

Поле `repeat_coins_reward` оставлено в БД для обратной совместимости,
но выплаты по нему больше не производятся.
