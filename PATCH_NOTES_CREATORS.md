# Патч системы креаторов

## Что изменено

- Система уровней креаторов переведена на ручное повышение через админ-панель.
- После одобрения заявки пользователь назначается официальным креатором 1 уровня.
- Уровни 1–5 теперь имеют редактируемые требования:
  - подписчики;
  - разыгранная сумма в монетном эквиваленте;
  - вступительные монеты;
  - недельные монеты;
  - количество Elite/Legendary паков;
  - ID паков для недельных наград;
  - лимит промокодов;
  - процент кода автора;
  - рейтинг эксклюзивной карты;
  - личные награды.
- Добавлен банк выдачи креатора:
  - можно добавить монеты;
  - можно добавить рубли;
  - можно добавить Rank-point;
  - можно добавить паки;
  - можно добавить карточки по ID экземпляра.
- После добавления награды в банк вывести её обратно нельзя.
- Разыгранная сумма засчитывается только после фактической выдачи игроку.
- Добавлен расчёт ценности выдачи:
  - 1 Rank-point = 40 000 монет;
  - 1 рубль = 10 000 монет;
  - 1 монета = 1 монета;
  - карточки считаются по цене быстрой продажи;
  - паки считаются по цене в магазине с конвертацией валюты.
- В панели креатора теперь отображается:
  - уровень;
  - канал;
  - подписчики;
  - всего разыграно;
  - текущая ценность банка;
  - требования текущего уровня;
  - доступные награды в банке;
  - возможности и личные награды уровня.
- Вступительные бонусы начисляются автоматически при первом назначении конкретного уровня.
- Недельные бонусы начисляются автоматически фоновым циклом раз в 168 часов.
- Ручная кнопка начисления недельных бонусов в админке сохранена.
- Ссылка на закрытый чат креаторов редактируется через админ-раздел и автоматически отправляется после одобрения заявки.
- Добавлены личные награды по умолчанию для уровней, которые можно заменить через админ-панель.

## Дополнение: стартовый ранг убран
- Уровни креаторов теперь только 1–5.
- После одобрения заявки креатор сразу получает 1 уровень.
- Вступительный бонус 1 уровня автоматически добавляется в банк выдачи при одобрении.
- Админка больше не принимает 0 как уровень креатора.
- Старые креаторы без ранга при запуске базы автоматически переводятся на 1 уровень.
