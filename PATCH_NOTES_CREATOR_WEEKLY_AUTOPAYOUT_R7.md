# Creator weekly bank auto-payout — R7

- Автоматическая выплата креаторам запускается фоновым watcher-ом из `main.py`.
- По умолчанию выплата каждые 168 часов; интервал и включение остаются в админ-настройках.
- Награды уровня (`weekly_coins`, Elite/Legendary packs) добавляются напрямую в банк креатора.
- Исправлена старая ошибка: UNIQUE `(user_id, bonus_type, level)` позволял weekly-бонусу пройти только один раз на каждом уровне.
- Weekly claims теперь имеют `period_key`, поэтому одна неделя платится строго один раз, а следующая — снова работает.
- Повторный scheduler tick / рестарт / второй инстанс не дублирует выплату за тот же период.
- Креатор получает Telegram-уведомление после фактического начисления.
- Ручная кнопка админа сохранена как отдельная принудительная выплата.
