# BLACK MARKET — гайд для бета-теста

Для тестировщиков, вручную проверяющих фичу в Telegram перед публичным релизом.

## Подготовка

1. Убедитесь, что в `.env` / Railway Variables задан `BLACK_MARKET_SEED_SECRET` (см. `PATCH_NOTES_BLACK_MARKET.md`, раздел 11). Если не задан — бот всё равно запустится (fallback на `BOT_TOKEN`), но в логах будет `WARNING`, это ожидаемо для локального теста.
2. Запустите бота, зайдите под тестовым админ-аккаунтом (ID из `ADMIN_IDS`).
3. Пул предметов изначально **пуст** — сначала нужно добавить хотя бы 1-2 товара через «➕ Добавить предмет», иначе у игроков ассортимент будет пустым (это не баг, это ожидаемое поведение при пустом пуле — экран покажет «Сегодня ассортимент пуст»).

## Сценарий 1 — Добавление товаров (админ)

Пройдите мастер «➕ Добавить предмет» для КАЖДОГО типа минимум по одному разу:
- **CARD** — введите ID существующей карты, убедитесь, что показывается фото-превью карты.
- **FRAME** — попробуйте оба пути: «Выбрать существующий» (если уже есть FRAME из CLAN WAR 2.0) и «Загрузить новый» (пришлите PNG).
- **BACKGROUND** — аналогично FRAME.
- **PACK** — выберите существующий пак из списка.
- **CURRENCY** — выберите валюту (`coins`/`energy`/...), укажите сумму награды.

Для каждого товара пройдите цену (проверьте оба режима — фиксированная и диапазон), сток (число и диапазон "2-5"), личный лимит, вес выбора, повторы, даты доступности (проверьте оба пути: пропустить и указать).

**Ожидаемо:** товар появляется в «📦 Пул предметов» с корректной меткой ✅ (активен).

## Сценарий 2 — Персональная витрина двух разных игроков

1. Откройте бота под Тестовым Игроком A → «🕶 Чёрный рынок» → запомните ассортимент (названия, цены).
2. Откройте бота под Тестовым Игроком B → «🕶 Чёрный рынок».
3. **Проверить:** если товаров в пуле больше, чем слотов, состав/порядок/цены (для RANDOM_RANGE) могут отличаться у A и B — это ожидаемо (персональная генерация).
4. Закройте и снова откройте магазин под Игроком A **в тот же день** — ассортимент должен быть **точно таким же**, включая цены и остатки (если ничего не покупали).

## Сценарий 3 — Покупка

1. Под Игроком A откройте товар → убедитесь, что видно: тип, редкость, цена, остаток, лимит, статус, фото-превью.
2. Нажмите «✅ Купить» → подтвердите.
3. **Проверить:** валюта списалась, награда пришла (карта/пак/фрейм/фон/валюта — соответствующая проверка: `/profile`, инвентарь косметики, паки).
4. Откройте товар повторно — остаток должен уменьшиться на 1.
5. Купите товар до конца стока (если сток маленький, например 1-2) — последняя попытка должна показать «Товар распродан».
6. **Проверить у Игрока B:** его остаток этого же товара НЕ изменился (разные витрины — разные остатки).

## Сценарий 4 — Двойной клик / повтор

1. Быстро нажмите «✅ Купить» дважды подряд (или откройте товар в двух вкладках Telegram, если возможно).
2. **Ожидаемо:** списание произошло только один раз (проверить баланс).

## Сценарий 5 — Недостаточно средств / лимит

1. С нулевым балансом попробуйте купить платный товар → ошибка «Недостаточно средств», сток/лимит не изменились.
2. Если у товара `personal_purchase_limit` меньше стока — купите до лимита, затем ещё раз → «Лимит покупок этого товара исчерпан», хотя сток может ещё быть > 0.

## Сценарий 6 — Админ: обновить рынок игрока / всем

1. «🔍 Найти игрока» → найдите Игрока A → «🔄 Обновить рынок этого игрока».
2. **Проверить:** Игрок A при следующем открытии получает **новый** ассортимент; Игрок B не затронут; в «📜 История ротаций» у A видна старая (EXPIRED) и новая (ACTIVE) запись.
3. «🔄 Обновить рынок всем» → подтвердить.
4. **Проверить:** это НЕ должно занять заметное время (мгновенный ответ — версия просто бампается); у ВСЕХ игроков при следующем открытии — новый ассортимент.

## Сценарий 7 — Включить/выключить магазин

1. «⚙️ Настройки ротации» → «🔴 Выключить магазин».
2. Игрок открывает «🕶 Чёрный рынок» → должен увидеть сообщение о временной недоступности, а не пустой экран/ошибку.
3. Включите обратно — магазин снова работает, старый ассортимент (если не истёк день) на месте.

## Сценарий 8 — Смена дня (business_date)

Это сложно проверить вручную без ожидания полуночи UTC — при необходимости обратитесь к разработчику для временной подмены системной даты в тестовом окружении, либо проверьте это через автоматические тесты (`tests/test_black_market_generation.py::test_same_user_different_business_date_gets_new_rotation`), которые уже покрывают эту логику.

## Сценарий 9 — Уведомления

1. В «⚙️» проверьте текущий `notification_target` (по умолчанию ALL).
2. После «Обновить рынок игрока» — тестовый игрок должен получить сообщение «🕶 Твой ассортимент Чёрного рынка обновлён» (личное, приходит сразу).
3. После «Обновить рынок всем» — рассылка идёт в фоне (не блокирует ответ админу), у активных игроков сообщение появится в течение нескольких секунд/минут в зависимости от их числа.

## Известные ограничения бета-версии

- Настройки `slots_count`/`stock_mode`/`allow_duplicate_slots` редактируются только напрямую в БД (сознательное решение — эти поля меняются редко, ошибка в них дороже, чем в весах редкости).
- Даты доступности (`available_from`/`available_until`) вводятся текстом в формате `ГГГГ-ММ-ДД ЧЧ:ММ:СС` без валидации формата на лету — при ошибке ввода товар может никогда не появиться (проверяйте на скрытых тестовых товарах перед продакшн-использованием).
