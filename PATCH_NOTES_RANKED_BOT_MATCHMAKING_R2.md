# Ranked bot matchmaking R2

- Ranked больше не подбирает случайного реального пользователя из БД.
- Каждый поиск матча создаёт бота.
- OVR бота: OVR состава игрока или ровно +1, максимум 99.
- Бот использует только реальные активные карты из общего каталога и только точного выбранного OVR.
- Для 3F/2D/1G допускаются повторные экземпляры одной карты, если уникальных карт точного OVR мало.
- Химия бота отображается, но не повышает скрыто его matchmaking OVR.
- Последние 8 ников ботов пользователя исключаются при следующем подборе, чтобы один и тот же ник не выпадал подряд.
