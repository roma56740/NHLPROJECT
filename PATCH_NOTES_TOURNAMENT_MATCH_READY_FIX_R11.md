# R11 — Creator Tournament match readiness fix

Исправляет ложный статус `failed / Составы не готовы к матчу` в турнирах креаторов.

## Причина
`play_player_match()` возвращает `(None, None)` не только при неполном составе, но и когда один из игроков уже занят глобальным match-lock в другом режиме. Турнирный код любую такую ситуацию записывал как `Составы не готовы к матчу`, после чего матч попадал в `⚠️ зависший` и требовал ручного восстановления создателем.

## Изменения
- До запуска симуляции отдельно проверяются оба обычных состава (3 FWD / 2 DEF / 1 G).
- Неполный состав больше не переводит матч в `failed`: матч остаётся `waiting`, а сообщение показывает игрока и заполненность, например `Devil (5/6)`.
- Отдельно проверяется глобальный match-lock. Если участник играет Ranked / Clan War 2.0 / Stronghold / обычный матч, турнир остаётся `waiting` и сообщает реальный режим, в котором занят игрок.
- Закрыта race-condition между preflight и фактическим acquire lock: транзиентный конфликт также возвращает матч в `waiting`.
- Старые матчи со старой точной ошибкой `Составы не готовы к матчу.` автоматически восстанавливаются в `waiting` при миграции. Это позволяет восстановить уже существующие зависшие матчи (включая сценарий вроде матча #280) без ручного SQL.
- `attempt_count` теперь увеличивается только при фактической попытке запуска движка, а не при ошибке готовности до запуска.
- Турнирные матчи больше не меняют обычный рейтинг/лигу, W/L-статистику, Coins, Rank Points, обычные quests/events и прогресс захвата Clan War арен. В истории они помечаются `opponent_type=tournament`.

## Проверки
- `python -m compileall app tests` — OK.
- Ручной SQLite integration smoke: 0/6 → waiting, после сборки составов матч завершается.
- Межрежимный lock Clan War 2.0 → waiting, после освобождения lock повторный запуск завершается.
- Legacy failed `Составы не готовы к матчу.` → автоматически возвращается в waiting.
- Турнирный матч не меняет normal rating / W-L / matches_played / Coins.

Полный pytest в текущем контейнере не запущен: отсутствует пакет `aiogram`.
